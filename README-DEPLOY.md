# בית הכנסת הגדול חדרה — מדריך פריסה ותחזוקה

אתר צד‑לקוח (React + Babel) עם **ניתוב URL אמיתי** ו‑**SEO סטטי לכל עמוד**.

---

## 1. איך זה עובד (בקצרה)

- כל עמוד מקבל כתובת אמיתית: `/`, `/about`, `/prayer-times`, `/gallery`,
  `/פרשת-השבוע`, `/heritage`, `/memorial`, `/contact`, `/donate`.
- כל פרשה מקבלת כתובת ייעודית בעברית: `/פרשת-השבוע/<שם-הפרשה>` (למשל `/פרשת-השבוע/נשא`).
- ניווט מעדכן את ה‑URL (History API), כפתורי אחורה/קדימה עובדים, ורענון מציג את העמוד הנכון.
- **SEO:** סקריפט בנייה (`build-seo.cjs`) מייצר **קובץ HTML סטטי לכל עמוד ולכל פרשה**,
  עם `<title>`, `meta description`, Open Graph, Twitter, canonical ו‑Structured Data (JSON‑LD)
  מוטמעים — כך שגוגל והרשתות החברתיות (וואטסאפ/פייסבוק) רואים תצוגה נכונה לכל קישור.
  בנוסף נוצרים `sitemap.xml` ו‑`robots.txt`.

### מקור אמת יחיד (Single source of truth)
כל התוכן והמטא־דאטה במקום אחד, ומשמש גם את האתר החי וגם את הבנייה הסטטית:

| קובץ | תפקיד |
|------|--------|
| `content/site.js` | הגדרות אתר: **דומיין**, שם, תמונת שיתוף ברירת מחדל, פרטי ארגון |
| `content/pages.js` | Title + Meta Description לכל עמוד סטטי |
| `content/parshiot.js` | רשימת הפרשות + הדרשות (מקור יחיד) |
| `index.template.html` | תבנית ה‑HTML שממנה נוצרים כל העמודים |

## 2. פריסה ל‑Vercel  (חשוב!)

הגדרות הפרויקט ב‑Vercel:

- **Framework Preset:** `Other`
- **Build Command:** `node build-seo.cjs`
- **Output Directory:** `.`  (נקודה — שורש הריפו)
- **Install Command:** אפשר להשאיר ריק

> למה צריך Build Command?
> תיקיות הפרשות נושאות שמות בעברית (`/פרשת-השבוע/נשא`). הבנייה ב‑Vercel
> יוצרת אותן אוטומטית (Vercel תומך בשמות קבצים בעברית). אם **לא** מגדירים
> Build Command — האתר עדיין יעבוד (ניווט + רענון דרך `vercel.json`),
> אבל עמודי הפרשות לא יקבלו מטא ייחודי לשיתוף עד שתופעל הבנייה.

קובץ `vercel.json` כבר כולל:
- `cleanUrls` — כתובות נקיות ללא `.html`.
- `rewrites` — כל כתובת שאין לה קובץ סטטי נופלת חזרה ל‑`index.html` (SPA fallback),
  כך שרענון בכל עמוד עובד.

## 3. הגדרת הדומיין (כשיהיה)

פתח את `content/site.js` ועדכן שדה אחד בלבד:

```js
url: 'https://hagadol-hadera.org.il',   // ← הכתובת הסופית, ללא לוכסן בסוף
```

בבנייה הבאה כל ה‑canonical, Open Graph, `sitemap.xml` ו‑`robots.txt`
יקבלו כתובות מלאות ומדויקות. אין צורך לגעת בשום מקום אחר.

> טיפ: ב‑Vercel אפשר גם להגדיר משתנה סביבה `SITE_URL` במקום לערוך את הקובץ.

## 4. הוספת פרשה חדשה (ללא שינוי קוד)

מוסיפים אובייקט חדש למערך ב‑`content/parshiot.js`:

```js
{
  name: 'נשא',                 // שם לתצוגה
  slug: 'נשא',                 // הכתובת תהיה /פרשת-השבוע/נשא  (רווחים => מקפים)
  title: 'פרשת נשא',
  subtitle: '״נשא את ראש בני גרשון״',
  excerpt: 'תקציר קצר לכרטיס ולתיאור החיפוש…',
  metaDescription: 'תיאור ל‑SEO (עד ~160 תווים)…',
  image: 'assets/heritage-historic.jpg',
  gradient: 'linear-gradient(160deg, #1f5b5e 0%, #0f3a3d 100%)',
  editions: [
    {
      year: 'תשפ״ו',
      date: 'י״ב סיון תשפ״ו',
      dateGregorian: '6 ביוני 2026',
      readingMinutes: 5,
      content: [ 'פסקה ראשונה…', 'פסקה שנייה…', 'פסקה שלישית…' ],
    },
  ],
}
```

הפרשה תקבל **אוטומטית**: כתובת ייחודית, Title, Meta Description, Open Graph,
Structured Data, והכללה ב‑`sitemap.xml`. (ב‑Vercel — מתעדכן בדיפלוי הבא.)

### ארכיון לפי שנים (מוכן לעתיד)
המבנה `editions[]` נועד לאחסן כמה גרסאות של אותה פרשה בשנים שונות.
כברירת מחדל מוצגת **הגרסה האחרונה** במערך, והכתובת נשארת `/פרשת-השבוע/נשא`.
בעתיד אפשר להוסיף גרסה נוספת (נשא תשפ״ז) בלי לשנות את הארכיטקטורה:

```js
editions: [
  { year: 'תשפ״ו', date: '…', dateGregorian: '…', content: [ … ] },
  { year: 'תשפ״ז', date: '…', dateGregorian: '…', content: [ … ] },  // ← תוצג כברירת מחדל
]
```

## 5. בנייה מקומית (אופציונלי)

```bash
node build-seo.cjs
```

מייצר את כל העמודים הסטטיים + `sitemap.xml` + `robots.txt` בשורש הפרויקט.
(בסביבת התצוגה המקדימה כאן תיקיות בעברית אינן נשמרות — לכן הן נוצרות בבנייה
אצלך/ב‑Vercel, שתומכים בשמות בעברית.)

---

## 6. מבנה קבצים

```
content/         מקור האמת (site, pages, parshiot)
seo/generate.js  מנוע ה‑SEO המשותף (ריצה + בנייה)
src/router.jsx   ניתוב צד‑לקוח + עדכון <head> חי
src/*.jsx        עמודי האתר (ללא שינוי עיצובי)
index.template.html   תבנית הבנייה
build-seo.cjs    סקריפט הבנייה הסטטית
vercel.json      כתובות נקיות + SPA fallback
```
